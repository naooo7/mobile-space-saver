# Home Hero Card Refinement

## Scope
- Replace only the current Home greeting area with one compact horizontal hero card.
- Keep every Home section below it unchanged.

## Implementation
- Use the selected academic prestige glass direction within FastLearner’s existing Liquid Glass and institution theme system.
- Keep greeting, motivational subtitle, streak, target label, institution name, and the real institution logo inside one card without nested cards.
- Use a black/charcoal surface with restrained institution-tinted border, glow, and gradient.
- Position the institution logo as a large, low-opacity, softly frosted background element on the right.
- Keep mobile height compact and preserve more breathing room on desktop through existing responsive breakpoints.

## Validation
- Check 360px, 390px, 430px, and desktop layouts.
- Confirm no clipping, horizontal overflow, console errors, or changes to sections below the hero.
- Confirm Light/Dark/System and institution accents remain readable and subtle.
